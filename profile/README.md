# Blaze Streaming Media

We build and operate live streaming systems for conferences, product launches, and broadcasts.

Our engineers work remotely alongside on-site production teams, handling video delivery, captioning, and multilingual streaming. That can mean a single keynote or dozens of simultaneous sessions, with monitoring and support throughout the event.

We use AWS and infrastructure as code to make event setups repeatable and easier to manage. Our repositories hold the tools, infrastructure, and applications that support that work.

If you're working with us, start with the README in your project’s repository for setup instructions and contribution guidelines.
